# PokéMemória

> Você conhece o Pokémon. Só esqueceu o nome dele.

Jogo web de nostalgia para adultos que cresceram com Pokémon e hoje,
entre trabalho, reuniões e boletos, já não lembram o nome de todos eles.

**Projeto independente e não oficial.** Sem afiliação com The Pokémon
Company, Nintendo ou Game Freak.

## Status

Em desenvolvimento. Estrutura inicial pronta (React, TypeScript, Vite e
Tailwind CSS). O jogo ainda será construído.

## Como executar

Pré-requisitos: [Node.js](https://nodejs.org) e [Git](https://git-scm.com)
instalados.

```bash
npm install
npm run dev
```

Depois abra no navegador o endereço mostrado no terminal
(normalmente http://localhost:5173).

## Tecnologias

- React
- TypeScript
- Vite
- Tailwind CSS
